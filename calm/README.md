# The Calm Tools

**Offline-first productivity tools to plan, track, and reflect. No accounts, no noise.**

---

## Philosophy

Modern productivity software is broken. Apps demand accounts, sync to servers you don't control, show notifications designed to pull you back in, and lock your data behind subscriptions. They optimize for engagement, not for helping you focus.

**The Calm Tools takes a different approach:**

### Principles

1. **Offline-first** — Every app works without an internet connection. Your data lives in your browser's localStorage. No servers required.

2. **Single-file architecture** — Each tool is a self-contained HTML file. No build steps, no dependencies, no frameworks. Just open in a browser and start working.

3. **Data ownership** — Export your data anytime as JSON. Import it anywhere. Your work belongs to you.

4. **Minimal by design** — No gamification, no streaks that guilt you, no social features, no AI suggestions. Just tools that do one thing well.

5. **No accounts** — No sign-up, no login, no password resets. Open the file and start.

6. **Respectful defaults** — Dark mode follows system preference. No permission popups. No newsletter modals. No cookie banners.

### Why "Calm"?

Productivity tools should reduce anxiety, not create it. These tools won't shame you for missing a habit, won't show you how your friends are doing, won't send you "you haven't logged in for 3 days" emails. They're here when you need them and invisible when you don't.

## Getting Started

### Installation

1. Download all HTML files to a folder
2. Open `index.html` in your browser
3. That's it. No installation, no setup.

### As a PWA (Progressive Web App)

For the best experience, install The Calm Tools as an app:

1. Open `index.html` in Chrome, Edge, or Safari
2. Look for "Install" in the browser menu (or the install banner)
3. The app will work offline and feel like a native application

### First Steps

1. **Start with Blueprint** — Plan your day each morning
2. **Add 2-3 habits to Streak** — Don't overwhelm yourself
3. **Use Capture liberally** — Get thoughts out of your head
4. **Check Pulse weekly** — See patterns in your data

## App Guides

### Pulse — Weekly Dashboard

Pulse pulls data from all your other apps and shows you the big picture.

**What you'll see:**
- This week's habit completion rates
- Total spending and top categories
- Recent journal entries and mood trends
- Active ideas in development
- Reading progress
- Workout frequency

**Tips:**
- Check Pulse on Sunday evenings for weekly review
- Use it to spot trends you might miss day-to-day

---

### Blueprint — Daily Planner

Your command center for each day.

**Sections:**
- **Why** — Set your intention for the day
- **Time Blocks** — Schedule your day in blocks
- **Tasks** — Action items to complete
- **Spending** — Track daily expenses

**Workflow:**
1. Each morning, fill in your "Why"
2. Block out your time
3. List 3-5 tasks (not 20)
4. Log expenses as they happen
5. Archive at end of day

**Tips:**
- Use the print feature for a paper backup
- Archived days can be reviewed anytime
- Keep tasks small and specific

---

### Anchors — Daily Journal

Structured reflection without the blank page anxiety.

**Features:**
- 120 rotating reflection prompts
- Mood tracking (1-5 scale)
- Gratitude entries
- Weekly review mode

**Prompts include:**
- "What's one thing you're avoiding?"
- "What would you do if you couldn't fail?"
- "What drained your energy today?"

**Tips:**
- You don't need to answer every prompt
- Skip what doesn't resonate
- Consistency matters more than length

## Data & Privacy

### Where is my data stored?

All data is stored in your browser's `localStorage`. It never leaves your device unless you:
1. Export it manually
2. Set up cloud sync

### How do I back up my data?

1. Press `D` to open Data Tools
2. Click "Export All Data"
3. Save the JSON file somewhere safe

### How do I restore a backup?

1. Press `D` to open Data Tools
2. Click "Import Data"
3. Select your backup JSON file

### Cloud Sync (Optional)

For syncing across devices:
1. Create a free account at [jsonbin.io](https://jsonbin.io)
2. Create a new bin
3. Copy the bin URL and API key
4. Press `S` and enter your credentials
5. Click "Save & Sync Now"

Use the same URL on other devices to sync data.

## Philosophy in Practice

### On Streaks

Streaks are a tool, not a goal. If you miss a day, the world doesn't end. The app won't send you notifications or show "streak lost" warnings. Just mark tomorrow and keep going.

### On Tracking

Track what matters. If something feels like a chore to track, maybe you don't need to track it. These tools work best when they reduce friction, not add it.

### On Simplicity

Each app does one thing. If you need a feature that doesn't exist, consider whether you really need it, or if the constraint is actually helpful.

### On Data

Your data is yours. Export regularly. The JSON format is human-readable and can be imported into other tools if you ever leave.
